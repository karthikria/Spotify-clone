# 🎵 Spotify Clone UI (React + Vite)

A Spotify-inspired music streaming web application built using **React**, **Vite**, and **Tailwind CSS**.  
This project focuses on recreating Spotify’s UI and basic music player functionality using **React Router** and **Context API**.

---







## 🚀 Features

- 🎧 Spotify-like modern UI
- ▶️ Play / Pause songs
- ⏭️ Next & Previous track controls
- 📀 Album-based navigation
- 🧭 React Router navigation
- ⏱️ Real-time progress bar & duration
- 🎶 Global audio control using Context API
- 📱 Responsive design with Tailwind CSS
- 🎬 Intro splash screen

## ▶️ How to Run This Project

### 1️⃣ Clone the Repository

git clone https://github.com/karthikria/Spotify-clone.git

### 2️⃣ Navigate to Project Folder

cd Spotify-clone

### 3️⃣ Install Dependencies

npm install

### 4️⃣ Start Development Server

npm run dev


### 5️⃣ Open in Browser

http://localhost:5173
